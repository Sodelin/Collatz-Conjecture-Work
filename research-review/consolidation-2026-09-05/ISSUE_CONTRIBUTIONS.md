## Unique issue #2 transfer argument

On normalized additive Haar measure of `X=Z_3^units`, the inverse branch `phi_a(m)=(2^a*m-1)/3` is defined with unit output on two of the six unit classes modulo9. The map `psi_a(n)=(3*n+1)/2^a` bijects X with that domain and scales measure by1/3. Thus the weighted operator

`Lf(m)=sum_(a>=1) (3/2^a)*1_(D_a)(m)*f(phi_a(m))`

preserves the integral of nonnegative measurable f. There is no nonzero nonnegative L1 function satisfying a uniform strict multiplicative contraction. This is an absolutely continuous averaged statement, not a claim that an exceptional positive orbit has positive Haar measure or that 3-adic state encodes the exact 2-adic selector.

The actual positive odd edge has `1/n-3/(2^a*m)=1/(2^a*m*n)>0`. Multiplication by the stated prefix multiplier telescopes exactly. The product/sum variables in the comments are normalized versions of the L1 affine correction. Preserve the final correction comment together with the original branch proposal; treating the earlier slow-escape alternative as current would undo the correction.

## Unique issue #3 correction-prime lemma

For increasing exponents A and `C_(k+1)=3*C_k+2^(A_k)`, `C_1=1`, every C is odd and prime to3. If their prime support were finiteP, then `3*C_k/C_(k+1)` and `2^(A_k)/C_(k+1)` would form infinitely many rational S-unit solutions to x+y=1 for S=P union{2,3}. Standard S-unit finiteness would repeat a pair, forcing `C_j=2^(A_j-A_i)*C_i`, contradicting oddness for j>i. This is a conditional application of a named classical theorem, with no new Lean proof.

The fixed orbit1 gives `C_k=4^k-3^k`, so infinitely many correction primes occur even though the orbit has no prime factors. This is a particularly useful false control: “new primes in the prefix identity” is not “new primes in the trajectory.”
