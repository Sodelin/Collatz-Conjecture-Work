HOSTILE-AUDIT CORRECTION
------------------------
The affine comparison helper previously recognized only strict leading-
coefficient decrease. It now also recognizes an equal leading coefficient
with a smaller intercept. The K=3..12 sweep counts below are unchanged.

Exact boundary regression: for every integer x>=0,

  U^4(8*x+5) = U^4(8*x+4) = 3*x+2,
  and 0 < 8*x+4 < 8*x+5.

This is the equal-slope case omitted by the original L5 completeness claim.

The final validator recomputes the exact uniform forward affine state, replays
every recorded parity branch symbolically, checks equality of the affine
target pair, and verifies the exact threshold. Concrete samples remain only as
a redundant implementation guardrail.

AUDIT CORRECTION
----------------
The first committed version artificially restricted the forward Collatz time to t<=K ordinary steps. That was too restrictive. A residue modulo 2^K fixes K *division-by-two decisions*, not merely K ordinary steps; intervening odd steps do not consume 2-adic precision. The script was rewritten to propagate the exact affine family until its x-coefficient becomes odd, which is exactly where parity begins to depend on x. Reverse/coalescence branches are now constructed symbolically rather than accepted from sample agreement.

The earlier shallow counts are therefore superseded by this file. Keeping this correction in Git history is intentional.

Exact coalescence certificate
-----------------------------
For every integer x>=0,

  N(x) = 64*x + 15
  m(x) = 54*x + 13

satisfy 0 < m(x) < N(x), and

  U^9(64*x+15) = 162*x+40 = U(54*x+13).

The direct uniform path of 64*x+15 has not descended by the last fully uniform state:

  U^9(N)  = 162*x+40
  U^10(N) = 81*x+20,

whose leading coefficient 81 is still larger than 64. At the next step parity depends on x. Thus this is a genuine example where a strong-induction coalescence certificate closes a cylinder that the direct uniform-descent test does not.

Interpretation
--------------
- Exact affine coalescence genuinely closes residue cylinders that have no uniform direct descent before the cylinder's parity information runs out.
- At K=12, this bounded search certifies 1903 of 2048 odd residue cylinders (about 92.9%) and leaves 145 unresolved.
- This percentage is diagnostic only. It cannot be extrapolated to a proof.
- Several unresolved branches persist coherently across increasing K, including Mersenne/-1-shadow-like cylinders. This is consistent with the old Round-4/5 lesson that arbitrarily long locally bad 2-adic shadows exist.
- The next target remains a finite recursive graph/state representation with ranked back-edges, or an equivalent mixed binary/ternary rewrite interpretation. Merely increasing K is not a resolution strategy.
