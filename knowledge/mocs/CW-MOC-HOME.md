# Collatz Work knowledge home

Use this map to see why a result exists, what it depends on, what it blocks,
and what evidence actually checks it.

1. Start with the [route map](CW-MOC-ROUTES.md).
2. Open the [claim map](CW-MOC-CLAIMS.md) for exact scoped status.
3. Follow [verification](CW-MOC-VERIFICATION.md) before trusting a `PASS` or
   a formalization claim.
4. Check the [failure map](CW-MOC-FAILURES.md) before reviving a mechanism.
5. Check [sources and priority](CW-MOC-SOURCES.md) before any public claim.
6. Use the [effective-flash map](CW-MOC-EFFECTIVE-FLASHES.md) for provisional
   issue-derived route notes that are not promoted claims.
7. Use the [publication map](CW-MOC-PUBLICATION.md) to see which independent
   gates block a candidate artifact.
