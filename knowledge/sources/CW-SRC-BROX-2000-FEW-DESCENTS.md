# Collatz Cycles with Few Descents

[Source index](INDEX.md)

## Citation and identifiers

T. Brox, *Acta Arithmetica* 92.2 (2000), 181–188. [DOI](https://doi.org/10.4064/aa-92-2-181-188)

[Open Zotero item](zotero://select/library/items/M4F2IKL2)

## Role in this project

Prior art for finiteness and exclusion techniques when a cycle has sufficiently few descents. It constrains the value of low-complexity pump languages.

## Audit boundary

Few-descents results do not bound arbitrary cycle words. A route must show its generated family satisfies the source's hypotheses before invoking it.

## Review checklist

- [ ] Verify the exact descent statistic and finiteness statement.
- [ ] Translate project valuation words into that statistic.
- [ ] Avoid extrapolation to unrestricted cycles.
