# Termination of String Rewriting with Matrix Interpretations

[Source index](INDEX.md)

## Citation and identifiers

Dieter Hofbauer and Johannes Waldmann, RTA 2006, LNCS 4098, 328–342. [DOI](https://doi.org/10.1007/11805618_25)

[Open Zotero item](zotero://select/library/items/UCZDQVH9)

## Role in this project

Foundational matrix-interpretation method for string rewriting and relative termination. It defines a major certificate family against which YAH searches and no-start results are scoped.

## Audit boundary

No result here says every terminating string system has such an interpretation. Failure at one dimension or representation does not refute termination.
