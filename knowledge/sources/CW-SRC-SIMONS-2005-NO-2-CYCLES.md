# On the Nonexistence of 2-Cycles for the 3x+1 Problem

[Source index](INDEX.md)

## Citation and identifiers

John L. Simons, *Mathematics of Computation* (2005). [DOI](https://doi.org/10.1090/S0025-5718-04-01728-4)

[Open Zotero item](zotero://select/library/items/BDMN9YEX)

## Role in this project

Published exclusion for positive cycles with two local minima, used to show why homogeneous two-run pump families are not a new disproof search space.

## Audit boundary

The theorem's “2-cycle” terminology concerns the source's local-minimum/cycle convention and must not be paraphrased without checking. It does not exclude all nontrivial Collatz cycles.

## Review checklist

- [ ] Verify the exact cycle definition and positivity assumptions.
- [ ] Map pump blocks to local minima without off-by-one errors.
- [ ] Compare the project search range with the published exclusion.
